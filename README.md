# Digital Libraries Final Project
## Who am I?
![Portrait of the this project's author, Logan Babcock.](https://luddy.iu.edu/images/grad-ambassadors/2025-26/logan-babcock.jpg)

My name is Logan Babcock and I'm a MLIS graduate student at IU Bloomington. This project is intended to demonstrate my technical skills in creating a digital collection. 
## What this project will be?
The scope of the digital collection is to be determined. The current ideas are the following:
1. Collection of military challenge coins
2. Collection of historical photographs of Indiana landmarks
3. Collection of 19th century Indiana state government publications
